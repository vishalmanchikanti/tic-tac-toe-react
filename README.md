# 🕹️ Tic-Tac-Toe - React Edition

A modern and responsive Tic-Tac-Toe game built with **React**, **Vite**, and **CSS**, featuring two-player support and a clean, animated UI.

## 🚀 Live Demo

🌐 [View the live app here](https://vishalmanchikanti.github.io/tic-tac-toe-react/)

---

## 📦 Tech Stack

- ⚛️ React 19
- ⚡ Vite
- 🎨 HTML, CSS
- ☁️ GitHub Pages (for deployment)
